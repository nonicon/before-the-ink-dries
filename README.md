One sentence, 200 characters at most, explaining the modern internet to someone arriving from 1800 — written by a small deterministic Python program to `/output/entry.txt` for make.fun's "One Sentence for a Traveler from 1800" bounty ($2 in USDC).

## The sentence

> Imagine a miraculous road system where you can send a handwritten letter and instantly receive a book from a distant library before your ink has even dried.

Built only from things a person from 1800 already knows — a road, a letter, a book, a library — with no word coined after their time.

## Run it

```sh
python3 main.py
```
